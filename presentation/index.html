🖥️ Computah

The Self-Verifying Computer for Coding Agents
Your agent ships a change. Computah opens it in a real browser, drives it toward your goal, and returns a PASS/FAIL verdict.

The Problem

AI coding agents face a critical gap:

  • They can write code, but cannot verify if it actually works
  • Manual QA testing closes the feedback loop slowly
  • Console errors and UI failures go undetected
  • The build → test → fix cycle depends on humans

Without verification:

Agent ships broken code → Human discovers → Agent re-runs → Repeat

The Solution

Computah closes the loop in seconds:

🌐 Real Browser

Opens your shipped UI in actual Chromium (via Playwright)

🤖 AI Driver

InsForge AI reads screenshots and executes your goal (click, type, navigate)

👁️ Error Detection

Watches console logs for errors and captures each step

✅ Instant Verdict

Returns PASS/FAIL + replay link in seconds

How It Works

Coding agent (Claude Code / Cursor / Devin) │ MCP tool: computah_verify({ url, goal }) ▼ Computah MCP server ──HTTP──► Next.js /api/verify │ ┌────────────────────┼─────────────────────┐ ▼ ▼ ▼ Playwright (Chromium) InsForge AI InsForge Storage + DB open · click · type · look at screenshot, screenshots + full screenshot each step pick next action, session for replay judge the goal │ ▼ Dashboard: live session replay + verdict

Demo: Login Page Verification

Agent: "I built a login page."

Project Architecture

  • src/lib/insforge.ts — InsForge admin client (DB · Storage · AI)
  • src/lib/verify.ts — The verification engine (Playwright agent loop)
  • src/app/api/verify — POST endpoint to run a verification
  • src/app/api/sessions — GET endpoints to list and fetch sessions
  • src/app/page.tsx — Dashboard (run console, view recent sessions)
  • src/app/sessions/[id] — Session replay player
  • mcp/server.ts — MCP tool: computah_verify

Getting Started

1. Create an InsForge Project

Visit insforge.dev and grab your API key

2. Set Up Schema & Storage

Run scripts/schema.sql in the InsForge SQL editor, then create a public bucket named computah-shots

3. Configure Environment

cp .env.example .env.local and fill in your credentials

4. Install & Run

npm install npx playwright install chromium npm run dev # http://localhost:3000

Deployment

🚀 Deploy to Vercel

Dashboard + API deploy seamlessly. Playwright serverless uses @sparticuz/chromium

🖥️ Custom Browser Worker

For heavy workloads, point /api/verify at a dedicated browser worker

Deploy Command

vercel --prod

The verification engine (src/lib/verify.ts) is transport-agnostic, so you can adapt it to any infrastructure.

Use with Your Agent

1. Start the MCP Server

npm run mcp

2. Register with Your Agent

For Claude Code, add to .mcp.json:

{ "mcpServers": { "computah": { "command": "npx", "args": ["tsx", "mcp/server.ts"] } } }

3. Call from Your Agent

computah_verify({ url: "http://localhost:3000/login", goal: "Log in and land on /dashboard" })
